The application uses a supplied ONNX export and extracted tokenizer vocabulary;
it does not retrain the model. The source model card documents thirteen languages,
including Tamil (speaker 18) and Malayalam (speaker 11), enabled in this app.
The supplied export's SHA-256 and runtime settings are recorded in config.json.
